# Уровни

## Как устроено

Уровень ставит **глыбу** и обстановку заказа: столик на `little`, леса на `medium`. Пол, стены, потолок и сквозной реквизит — комната (`createRoom`): создаётся один раз на сессию, при смене заказа не пересобирается. Склеивает `Game.buildLevel()`. Очередь заказов — `catalog.ts` (`nextPlayable`).

`little` — сетка `[11, 9, 10]`, столик высотой `tableVoxels` (3) с выступом `tableMargin`, глыба на нём. `small` — `[11, 12, 10]`, на полу, лесов нет. `medium` — `[26, 33, 16]`, леса буквой П с ±Z, настил `deckTops` `[5]`. Спавн с юга, спиной к двери.

Очередь: 1 лягушка (`little`), 2 птенец (`little`), 3 будда (`medium`). `small` в каталоге нет. Спавн первого заказа с юга, спиной к двери; следующего — у кровати, взгляд как перед сном.

### Фигура

- Будда — `assets/vox/buddha.vox`. Файл `24 14 32` → игра `24×32×14`. Сидит на `y = 0`. Сетка `medium` на клетку шире с боков и сверху.
- Лягушка — `assets/vox/frog.vox`. Плагин в `vite.config.ts` + `vox.ts`: Z-up → Y-up, `(mx,my,mz)` → `(mx,mz,my)`. Файл `9 8 8` → игра `9×8×8`. Лапы на `y = 0` сетки; сетка стоит на столике, поэтому фигура выше пола на три кубика.
- Птенец — `assets/vox/chick.vox`. Файл `6 8 9` → игра `6×9×8`. В уровне разворот 180° вокруг Y. Лапы на `y = 0` сетки (столик, как у лягушки). Высота 9 совпадает с `little`, сверху скорлупы нет.
- Занятая клетка `.vox` — скульптура. Пустота доливается мрамором (`createShapeLevel`). RGB в `LevelData.paint`, вскрывается после зачистки.
- Крест — доли габарита, `crossLevel.ts`. В меню нет, тесты арены ещё на нём.

`npm run export:duck` отключён: затрёт авторский `chick.vox`.

## Порядок: новый заказ

1. Файл `src/domain/levels/<имя>Level.ts` или `.vox` по образцу птенца.
2. Строка в `LEVELS`. Порядок массива = очередь кровати.
3. Сетка на клетку шире модели по осям, кроме пола, если фигура сидит на нём.
4. Постер заказа: `assets/images/model_posters/<id>_poster.png` и ключ в `MODEL_POSTERS` (`workshopPoster.ts`).
5. `npm test`, потом `npm.cmd run dev`.

## Чеклист фигуры

- [ ] Не на оболочке (кроме лап на столе у лягушки и птенца, на полу у будды; у птенца ещё и макушка — сетка `little` впритык по высоте)
- [ ] Нет дыр: предикат не оставляет воздух внутри объёма
- [ ] Весь мрамор достижим, фигура не делит его на полости
- [ ] Правка `.vox` → обновить страницу, плагин подхватит

## Чеклист лесов

- [ ] Лестница сплошная, список `ladders`
- [ ] Нет хардкода координат — только `CONFIG.arena`
- [ ] Тест досягаемости зелёный после смены `deckTops` / `deckGap` / `sizes`
