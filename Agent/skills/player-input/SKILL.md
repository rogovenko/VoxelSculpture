# Игрок и ввод

## Как устроено

Тело — AABB, `PlayerBody.ts`. Камера — глаза, yaw/pitch, FOV, kick. Ввод — `InputController.ts`: pointer lock обязателен, игра стартует только в `onLockGained`.

| Клавиша | Действие |
| --- | --- |
| WASD | Ход относительно взгляда |
| Space | Прыжок с опоры, на лестнице нет |
| C (держать) | Присед, рост и глаза × `crouchScale`. **Не Ctrl** — закрывает вкладку |
| Shift | Спуск по лестнице, не присед |
| W у лестницы снаружи | Подъём; верх опоры = настил |
| ЛКМ | Долбёжка. Реквизит с хинтом — мысль, магазин (телефон), ТЗ (письмо), дневник, сдача (стол), сон (кровать после сдачи) |
| ПКМ | Шире FOV |
| Esc | Снятие lock → пауза. Статистика — только стол, не Esc. В магазине — повесить трубку, в письме — закрыть. Во время сна (затемнение) пауза не открывается |

После Esc браузер ~1400 мс не даёт pointer lock снова (`POINTER_LOCK_COOLDOWN_MS`). Кнопка «Продолжить» ждёт этот кулдаун. Магазин снимает lock сам — кнопки сразу живые.

Изнутри лесов вверх не залезть: настил над головой. Лестница сплошная.
