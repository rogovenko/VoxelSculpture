# Архитектура

## Как устроено

```
domain/   чистый TS, без Three
view/     Three.js
app/      цикл, ввод, склейка
ui/       DOM-оверлеи
```

Числа игры — только `src/config.ts`. Комментарии в коде — по-русски, там где неочевидное ограничение.

## Куда смотреть

- Слои и решения: `Agent/Documentation/TechPlan.md` (если не хватило)
- Точка входа: `src/main.ts`, `src/app/Game.ts`
- Каталог уровней: `src/domain/levels/catalog.ts`

## Порядок

1. Новая игровая логика — в `domain/`. Рендер — в `view/`. Склейка — в `Game`.
2. Не тащи Three в domain. Не клади магические числа в логику.
3. Картинка и коллизия арены — один список коробок (`arena.boxes` + `ladders`).
4. После правки инвариантов: `npm test`. Глазами: `npm.cmd run dev`.

## Чеклист

- [ ] Domain не импортирует `three`
- [ ] Новое число попало в `config.ts`
- [ ] Нет второго списка геометрии «для картинки»
- [ ] Тесты не плодятся без просьбы
- [ ] Знания новой зоны — новый skill и строка в маршрутизаторе
