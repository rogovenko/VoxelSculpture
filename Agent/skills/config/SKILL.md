# Конфиг

## Как устроено

Масштаб задаёт **игрок**, не воксель. `VOXEL = 0.25`. Сетку можно дробить: `sizes` умножь во столько же раз, габариты игрока не трогай.

| Ключ | Сейчас | Смысл |
| --- | --- | --- |
| `grid.sizes.little` | `[11, 9, 10]` | Лягушка и птенец, столик. Мир `2.75 × 2.25 × 2.5` на высоте `0.75` |
| `grid.sizes.small` | `[11, 12, 10]` | На полу, в меню нет. Мир `2.75 × 3 × 2.5` |
| `grid.sizes.medium` | `[26, 33, 16]` | Будда, леса. Мир `6.5 × 8.25 × 4` |
| `chisel.dps` | `2.5` | Не выше 4 |
| `chisel.marbleHp` / `sculptureHp` | `1.0` / `1.4` | На клетку, при дроблении зерна не делить |
| `chisel.reach` | `3` | Мировые. Ломает досягаемость |
| `interact.reach` | `3.2` | Подсветка стола: луч до AABB |
| `player.*` | рост `2.95`, глаза `2.7` | Мировые. Присед `crouchScale` 0.5 |
| `arena.deckTops` | `[5]` | Настил один: под ним полный рост |
| `arena.tableVoxels` | `3` | Высота столика `little` в клетках |
| `arena.tableMargin` | `0.2` | Выступ стола за глыбу с каждой стороны |
| `arena.spawnFromDoor` | `2` | Спавн от стены с дверью (первый заказ и «Начать заново») |
| `arena.bedSpawnGap` | `0.3` | Зазор от AABB кровати до игрока после сна |
| `arena.floorOverhang` | `1.4` | Пол за стены, без коллизии |
| `arena.floorTile` | `4` | Повтор дерева на полу |
| `arena.ceilingTile` | `4` | Повтор бетона на потолке |
| `arena.wallTilesAlong` / `wallTilesUp` | `5` / `2` | Плиток модуля стены на сторону |
| `arena.rugScale` / `rugLift` | `0.02` / `-0.05` | Масштаб комплекта, ковёр в пол |
| `arena.layoutSnap` | `0.25` | Шаг драга в /editor.html |
| `colors.marble` | запас без текстуры | Камень рисует `diorite.png` |
| `colors.ceiling` | `0xffffff` | Запас; вид задаёт `Concrete_Tex.png` |
| `colors.shard` | `0xeef1f6` | Осколки светлее и холоднее глыбы |
| `colors.sculpture*` | зелёный / жёлтый / алый | Пока долбишь; после `.vox` — палитра |
| `colors.background` | `0x8eb6d4` | Небо за окнами |
| `money.centsPerBlock` | `1` | Цент за снятый мрамор; на экране доллары |
| `money.startCents` | `0` | Старт без денег |
| `money.payouts` | frog 1000 / chick 2000 / buddha 50000 | Оплата за сданный заказ, центы. Один раз со стола |
| `sleep.fadeOut` / `hold` / `fadeIn` | 0.85 / 1.4 / 0.9 | Секунды затемнения, паузы с «День N», прояснения |
| `cues.thoughtMs` / `hintMs` | 2800 / 4500 | Сколько висит мысль: клик / сюжет |
| `cues.milestones` | 1, 10, 50, 100, 200, 300, 400, 500, 666, 800, 1000, 1250, 1500, 2000 | Пороги сколов за кампанию |
| `effects.hasteMultiplier` | `2` | Множитель DPS сигареты |
| `effects.shop` | сигареты 50¢/20с, пиво $5/20с, кристалл $10/60с | Магазин телефона |

## Куда смотреть

- Файл: `src/config.ts`
- Таблица каждого поля: `Agent/Documentation/ConfigReference.md`

## Порядок

1. Одно число за раз.
2. `npm test` — упавший тест значит сломана раскладка или физика, не «тест плохой».
3. Потом смотри в игре.

## Чеклист связок

- [ ] `min(deckTops) - plateThickness > player.height` (сейчас 4.75 > 2.95)
- [ ] Оболочка глыбы досягаема: `reach`, `eyeHeight`, `deckTops`, `deckGap`
- [ ] `width`/`height` чуть меньше кратного `voxelSize`
- [ ] Сессию считай руками: мраморных клеток × `marbleHp` / `dps`
- [ ] Быстрее посмотреть заказ — ваншот в меню Esc, не крути `dps`
