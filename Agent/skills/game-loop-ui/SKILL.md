# Игровой цикл и UI

## Как устроено

Состояния: `start` | `playing` | `paused` | `shop` | `letter` | `win`.

Старт всегда лягушка. Квадратиков заказа нет: «Начать» берёт pointer lock, спавн у южной двери.

Зачистка (`levelCompleted`): `finished = true`, `revealPaint`, счёт в `pendingScore`, **остаёмся в playing**. Ходить можно, долбить больше нельзя. Оверлей «Работа принята» — только стол (`statsRequested` в `pause`). Esc после зачистки — обычная пауза.

Время сессии — от первого удара до кадра последней клетки мрамора, не до сдачи.

Оплата заказа (`CONFIG.money.payouts`) — один раз при первой сдаче стола. Повторный стол показывает те же цифры, без второй выплаты. Со статистики «Вернуться в мастерскую»: lock снова, фигура на месте.

Кровать до сдачи — мысль «Сон для слабаков». После сдачи: ввод замирает, экран темнеет, «День N», грузится следующий заказ (эффекты сброс, касса нет), спавн у кровати **с тем же взглядом, что при «лечь»**, экран светлеет. После Будды кровать открывает «Поздравляем!»; «Начать заново» возвращает на титульный экран (лягушка, `startCents`). Длительности — `CONFIG.sleep`.

Рестарт сессии пересобирает уровень, не страницу. Смена `small`/`medium` пересобирает арену.

Отладка в паузе только при `import.meta.env.DEV`: квадратики заказов, ваншот и «оставить один воксель». Старт всё равно лягушка.

Сверху в `playing` — `MarbleBar`: тёмная плашка, снятый мрамор / остаток, выезжает сверху; прячется на паузе и победе.

Справа сверху — `WalletHud` («Наличные»): доллары, `+$` при снятии мрамора. 1 клетка = `CONFIG.money.centsPerBlock` центов. Касса сессионная, переход по кровати не обнуляет. «Начать заново» после финала — да. Отладка «оставить один воксель» не платит.

Под кассой — `EffectHud`: плашки баффов (эмодзи + таймер). Тикает только в `playing`.

Телефон: взгляд + ЛКМ → `shop` (`ShopOverlay`). Lock снимается без паузы и без победы. Товары — `CONFIG.effects.shop`. Не хватает денег — кнопка бледная. Бафф ещё висит — «Я совсем недавно курил/пил/нюхал». «Повесить трубку» сразу, без паузы 1.4 с (это только после Esc). Касса и плашки эффектов в магазине остаются.

Письмо: взгляд + ЛКМ → `letter` (`LetterOverlay`). Текст ТЗ текущего заказа (`briefLetters.ts`), кнопка «Закрыть» / Esc. Как магазин: lock снимается сам, таймеры стоят. Текст на кремовом бланке (`.letter-sheet`), не на тёмной вуали. Открытие: бланк выезжает снизу и проявляется (`is-in`); закрытие — тот же ход обратно.

Дневник: между письмом и телефоном. Тот же оверлей, класс `is-diary` — разлинованная тетрадь. Записи по заказу (`diaryEntries.ts`).

Всплывающие мысли (`InteractHint.cue`, тексты в `cues.ts`): тёмная плашка, как у подсказки взаимодействия. После «День 1» — прочитать ТЗ; после зачистки — сдать за столом; после статистики — в кровать; после сна — «Новый день». Первый удар по оригиналу — предупреждение. Пороги сколов за кампанию (`CONFIG.cues.milestones`). Клик по реквизиту (`think`) сбрасывает очередь.

Подсветка реквизита: снизу `InteractHint` (стол, телефон, письмо, дневник, кровать, кресло, коробки, кабинет, дверь, телевизор). ЛКМ по столу до зачистки — мысль «Заказ еще не готов!»; после зачистки — сдать работу. Письмо — «Прочитать ТЗ». Дневник — «Открыть дневник». Остальные клики — реплика, кроме телефона (магазин) и кровати после сдачи.

## Порядок: правка победы

1. Условие зачистки не трогай в домене — это ноль мрамора.
2. Когда показывать UI — только стол / финальная кровать через флаги в `pause`.
3. Вердикт и цифры — `ScoreSystem` + `WinOverlay`.

## Чеклист

- [ ] После последней клетки мрамора нет мгновенного оверлея
- [ ] Esc после зачистки — пауза «Продолжить», не статистика
- [ ] Статистика — стол; оплата один раз
- [ ] Кровать после сдачи: затемнение, «День N», следующий заказ у кровати с тем же взглядом; после Будды — финал
- [ ] «Начать заново» после финала — титульный экран, лягушка, стартовая касса; «Начать» как в первый раз
- [ ] Счёт не растёт, пока игрок ходит вокруг готовой фигуры
