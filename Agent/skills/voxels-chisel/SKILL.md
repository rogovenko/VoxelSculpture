# Воксели и долбёжка

## Как устроено

`VoxelGrid` из `LevelData`. Мрамор снимается, скульптура остаётся. Победа по домену — `marbleRemaining === 0`.

Рейкаст — DDA в клетках. Дальность руки в мире / `voxelSize`. Подсветка — `HighlightBox`, не рамка в шейдере.

Урон необратим. Стадии трещин из HP. Добитую скульптуру не удаляют; трещины на время снимают (`stage = -1`).

После зачистки `revealPaint`: RGB из `paint`, урон поверх (краснота + затемнение), на добитых возвращается последняя стадия трещин. У `.vox`-заказов палитра есть; процедурный крест без `paint` остаётся зелёным.

Инстансы: swap-remove, карты `slotOfVoxel` / `voxelOfSlot`. Забыл обновить — трещины на чужой клетке.

## Порядок: правка вида клетки

1. Шейдер — `voxelMaterial.ts`. Не возвращай затемнение рёбер.
2. Атрибуты инстанса — не забудь копировать в `removeVoxel`.
3. Покраска — `aPaint` / `uRevealPaint`, вызов `revealPaint(grid)` при зачистке.

## Чеклист

- [ ] Мрамор удаляется, скульптура нет
- [ ] `voxelDamaged` / `removeVoxel` ходят через одну карту слотов
- [ ] После зачистки цвет `.vox` есть, царапины видны
- [ ] Ваншот действует только на мрамор
- [ ] Спешка множит `dps` (`hasteMultiplier`), аккуратность не даёт урон по скульптуре
- [ ] «Оставить один воксель» не шлёт тысячи событий осколков
