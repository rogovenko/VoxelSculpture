# SculptureCraft

Браузерный прототип шуточного симулятора скульптора: воксельная глыба мрамора, внутри скрытая форма, долбёжка удержанием ЛКМ.

Документация. Первые три отвечают на «что и почему», последние три — на «как поменять»:

- [GDD](Agent/Documentation/GDD.md) — что за игра и зачем
- [Техплан](Agent/Documentation/TechPlan.md) — архитектура и принятые решения
- [Гайд реализации](Agent/Documentation/ImplementationGuide.md) — пошаговая сборка проекта с нуля
- [Справочник по конфигу](Agent/Documentation/ConfigReference.md) — все числа игры, что чем правится и что нельзя ломать
- [Уровень](Agent/Documentation/LevelAuthoring.md) — заменить скрытую фигуру, сменить разрешение сетки, настроить леса
- [Сцена](Agent/Documentation/SceneAuthoring.md) — модели вместо коробок, текстуры, декорации с коллизией

Три последних написаны как самостоятельные инструкции: каждую можно выполнять, не читая остальные.

## Отладка

В `npm run dev` по **Esc** в меню паузы есть блок «Отладка»: тумблер «Ваншот» (мрамор с одного касания) и кнопка «Оставить один воксель» (снимает весь мрамор, кроме ближайшей к игроку клетки). После последней клетки мрамора фигура красится в цвета из `.vox`, ходить ещё можно; экран «Работа принята» открывается по Esc. В собранной версии блок отладки не монтируется.

## Запуск

```bash
npm install
npm run dev
```

Сборка и проверка:

```bash
npm run build
npm test
npm run lint
```
